# VoiceAnywhere 浏览器扩展

在任何网页的输入框用语音输入文字——点右下角绿色麦克风即可。

## 加载方式（开发者模式，不需发布商店）

### Chrome / Edge / 360 / 夸克（Chromium 内核）

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 右上角打开 **「开发者模式」**
3. 点 **「加载已解压的扩展程序」**
4. 选择这个目录：`calendar-app/extension/`
5. 加载成功后，所有网页右下角会出现一个绿色 🎙 按钮

> 夸克：本身基于 Chromium，但 `SpeechRecognition` 在夸克里实现不完整，可能点按钮提示"当前浏览器不支持"——这是浏览器限制不是扩展 bug，换 Chrome 即可。

### Safari（macOS）

Safari 扩展机制不同，本扩展暂不支持。

## 使用方式

1. 打开任意网页，把光标点击到你要输入的输入框（搜索框、聊天框、编辑器都行）
2. 点右下角绿色 🎙
3. 第一次使用会弹出麦克风权限请求——点"允许"
4. 说话 → 识别完成后文字自动出现在输入框（保持光标位置）

## 识别范围

- 中文（普通话 zh-CN）
- 单次识别（连续识别需要把模型改成 continuous，暂未启用）
- 识别完文字直接填入，不自动发送

## 当前限制

- **必须用 Chrome/Edge/360**——夸克不支持网页语音（之前验证过）
- 依赖浏览器内置 `SpeechRecognition`，需要连接浏览器厂商服务器：
  - Chrome → Google（国内可能不稳）
  - Edge → 国内访问较稳
  - 如果 Chrome 也不稳定 → 未来加讯飞/百度 ASR 兜底（需要你注册一个账号）
- 页面加载后即刻可见；SPA 切换页面会自动重新注入
- 不支持富文本编辑器的某些复杂格式（富文本里插入纯文本 OK，但样式/光标位置可能不完美）

## 跨域与权限

- 扩展在所有页面注入一个按钮（host_permissions: `<all_urls>`）
- 只读取麦克风录音和点击事件
- 不会上传你的语音到任何地方（浏览器厂商服务器除外）
