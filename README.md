# SchedulingTool

> AI 驱动的智能日程助手，支持自然语言录入、图片识别、跨设备云同步。
> （纯用workbuddy搓出来的

🔗 **在线体验**：https://792a2fbf0e9f4fb98b41d7f2bd5d40ef.app.workbuddy.link

---

## ✨ 功能亮点

| 功能 | 说明 |
|------|------|
| 🤖 **AI 自然语言解析** | 直接输入「明天下午3点开会」「9月10日11点到12点半上课」，自动提取日期、时间、标题 |
| 📷 **图片识别** | 上传课程表、活动通知截图，AI 自动识别日程并提取地点、状态等辅助信息 |
| ☁️ **跨设备同步** | 登录后数据自动同步到云端，电脑、手机随时访问 |
| 🎨 **交互优化** | 拖拽上传图片、自定义拖拽条调节输入框高度、响应式布局 |
| 🔒 **数据隔离** | 每位用户数据独立存储，空白初始状态，保护隐私 |

---

## 🖼️ 使用示例

**文字录入**
```
明天下午3点开会
9月10日 11点到12点半 上课
下周一上午10点 考试
```

**图片识别**
- 支持截图、拍照上传
- 自动识别日期（支持 `YYYY-MM-DD`、`24 Aug 2026`、`2026年8月24日` 等多种格式）
- 地点、举办方、报名状态等辅助信息自动归入备注

## 🏗️ 技术架构

```
┌─────────────┐      ┌──────────────────┐      ┌─────────────────┐
│   前端      │      │   Cloudflare     │      │   智谱 AI       │
│  React +    │ ───► │   Worker         │ ───► │  GLM-4-flash   │
│  TypeScript │ ◄─── │  (LLM 代理)      │ ◄─── │  GLM-4v-flash  │
└─────────────┘      └──────────────────┘      └─────────────────┘
       │
       ▼
┌─────────────┐
│  Supabase   │
│ (PostgreSQL)│
└─────────────┘
```

- **前端**：React 18 + TypeScript + Vite，部署于 CloudStudio
- **LLM 代理**：Cloudflare Worker，调用智谱 GLM-4 / GLM-4v 模型
- **云数据库**：Supabase，RLS 策略保障用户数据隔离
- **同步策略**：last-write-wins + `updatedAt` 时间戳，解决并发冲突
